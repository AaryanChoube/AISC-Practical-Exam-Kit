💡 Quick Viva Cheat Sheet:
  • Syllabus Reality: Exp 5 is strictly SWI-PROLOG. All other coding experiments (2, 3, 4, 6, 7, 8, 9) are in Python!
  • Water Jug Problem: Solvable iff $d \le \max(J_1, J_2)$ and $d \pmod{\gcd(J_1, J_2)} == 0$. BFS guarantees minimum pours!
  • Minimax & Alpha-Beta: Two-player zero-sum tree. Alpha: MAX best lower bound; Beta: MIN best upper bound. Prunes branch when $eta \le lpha$.
  • A* Search: $f(n) = g(n) + h(n)$. Heuristic is Admissible if $h(n) \le h^*(n)$ (never overestimates). Guarantees optimal path!
  • PROLOG Logic: Horn Clauses + Unification + Backtracking (DFS). Cut operator (!) stops backtracking.
  • Perceptron: Weight update: $w_i \leftarrow w_i + \eta(y - \hat{y})x_i$. SLP fails on XOR because XOR is non-linearly separable. MLP with hidden layers solves XOR!
  • McCulloch-Pitts: Binary threshold neuron with fixed weights. AND (thresh=2), OR (thresh=1), NOT (thresh=0, weight=-1).
  • Fuzzy Sets: Union = $\max$, Intersection = $\min$, Complement = $1 - \mu$. Defuzzification uses Centroid method.
  • Text Preprocessing: Lowercase -> Remove URLs/HTML -> Remove Punctuation -> Remove Numbers -> Whitespace trim -> Tokenize.

## 🤖 MODULE 1: AI AGENTS & PEAS FRAMEWORK (EXPERIMENT 1)
Q1: What is an AI Agent? What is an Agent Function vs Agent Program?
- Agent: Anything that perceives its environment through sensors and acts upon that environment through actuators.
- Agent Function: Mathematical mapping from percept sequence to action: f: P* -> A.
- Agent Program: Concrete software implementation executing on a physical architecture.

- E (Environment): Roads, vehicles, pedestrians, weather conditions, traffic signs.
- A (Actuators): Steering wheel, accelerator, brakes, horn, turn signals.
- S (Sensors): Cameras, LiDAR, radar, GPS, speedometer, accelerometer.

## 🚰 MODULE 2: STATE SPACE SEARCH & WATER JUG PROBLEM (EXPERIMENT 2)
Q4: Formulate the Water Jug problem as a State Space Search.
- State: (x, y) where x in [0, J1] and y in [0, J2]. Initial: (0, 0). Goal: (d, *) or (*, d).
- Operators: Fill J1, Fill J2, Empty J1, Empty J2, Pour J1->J2, Pour J2->J1.

Q5: What is the solvability condition?
- Solvable iff d <= max(J1, J2) and d % gcd(J1, J2) == 0 (Bezout's Identity).
- For 4L and 3L: gcd(4, 3) = 1. Since 2 % 1 == 0, 2 gallons is solvable!

Q6: Why BFS over DFS for Water Jug?
- BFS uses FIFO queue, exploring level-by-level. It guarantees finding the shortest solution path (minimum number of pours). DFS can loop infinitely or find long sub-optimal paths.

## 🎮 MODULE 3: GAME PLAYING & MINIMAX (EXPERIMENT 3)
Q7: What is Minimax?
- Adversarial search algorithm for 2-player, zero-sum, deterministic, perfect-information games.
- MAX player maximizes score (+10), MIN minimizes (-10).

Q8: What is Alpha-Beta Pruning? Pruning condition?
- Alpha (a): Best value MAX can guarantee (lower bound, starts -inf).
- Beta (b): Best value MIN can guarantee (upper bound, starts +inf).
- Prune branch when b <= a. Reduces optimal time complexity from O(b^m) to O(b^(m/2)).

## 🧭 MODULE 4: INFORMED HEURISTIC SEARCH (A* SEARCH) (EXPERIMENT 4)
Q9: Explain A* evaluation function f(n) = g(n) + h(n).
- g(n): Exact cost accumulated from start node to node n.
- h(n): Estimated (heuristic) cost from node n to goal.
- f(n): Total estimated cost of cheapest solution path passing through n.

Q10: What is an Admissible Heuristic?
- Never overestimates the true cost: h(n) <= h*(n). Guarantees A* is complete and optimal!
- Consistency (monotonicity): h(n) <= cost(n, a, n') + h(n').

## 📜 MODULE 5: LOGIC PROGRAMMING & PROLOG (EXPERIMENT 5)
Q11: What logic paradigm does PROLOG use?
- Declarative logic programming based on Horn Clauses (First-Order Predicate Logic).
- Execution uses Resolution Refutation + Unification + Backtracking (DFS).

Q12: What is the Cut operator (!) in PROLOG?
- Built-in predicate that commits to choices made since parent goal was invoked, preventing backtracking.
- Green Cut: Improves efficiency without altering solutions.
- Red Cut: Changes program logic and solution set.

## 🧠 MODULE 6: NEURAL NETWORKS & PERCEPTRON (EXPERIMENT 6 & 7)
Q13: Explain McCulloch-Pitts Neuron vs Perceptron.
- McCulloch-Pitts: Fixed weights (+1), binary inputs {0, 1}, hard threshold theta.
- Perceptron: Learnable real-valued weights and bias: w_i <- w_i + eta*(target - actual)*x_i.

Q14: Why does Single-Layer Perceptron fail on XOR?
- XOR is non-linearly separable. No single straight line / hyperplane can separate (0,1),(1,0) from (0,0),(1,1).
- Multi-Layer Perceptron (MLP) solves XOR using hidden layers + non-linear activation + Backpropagation.

## 🌫️ MODULE 7: FUZZY SETS & FUZZY LOGIC (EXPERIMENT 8)
Q15: Crisp Set vs Fuzzy Set:
- Crisp: Binary membership mu in {0, 1}.
- Fuzzy: Gradual membership degree mu(x) in [0, 1].

Q16: Standard Fuzzy Operations:
- Union: max(mu_A, mu_B)
- Intersection: min(mu_A, mu_B)
- Complement: 1 - mu_A
- Max-Min Composition: mu_T(x, z) = max_y(min(mu_R(x, y), mu_S(y, z)))

Q17: What is Defuzzification?
- Conversion of fuzzy output distribution into a single crisp scalar. Centroid method: z* = sum(z*mu(z)) / sum(mu(z)).

# Experiment 2: Water Jug Problem (Python State Space Search)
from collections import defaultdict

jug1, jug2, aim = 4, 3, 2
visited = defaultdict(lambda: False)

def waterJugSolver(amt1, amt2):
    if (amt1 == aim and amt2 == 0) or (amt2 == aim and amt1 == 0):
        print(f"Goal Reached: ({amt1}, {amt2})")
        return True

    if not visited[(amt1, amt2)]:
        print(f"State: ({amt1}, {amt2})")
        visited[(amt1, amt2)] = True

        return (waterJugSolver(0, amt2) or                          # Empty Jug 1
                waterJugSolver(amt1, 0) or                          # Empty Jug 2
                waterJugSolver(jug1, amt2) or                       # Fill Jug 1
                waterJugSolver(amt1, jug2) or                       # Fill Jug 2
                waterJugSolver(amt1 + min(amt2, (jug1 - amt1)),      # Pour Jug 2 -> Jug 1
                               amt2 - min(amt2, (jug1 - amt1))) or
                waterJugSolver(amt1 - min(amt1, (jug2 - amt2)),      # Pour Jug 1 -> Jug 2
                               amt2 + min(amt1, (jug2 - amt2))))
    else:
        return False

print("=== Water Jug Problem (Capacities: 4L, 3L | Goal: 2L) ===")
waterJugSolver(0, 0)
☕ View Java Alternative (WaterJugSolver.java) 
import java.util.*;

public class WaterJugSolver {
    static class State {
        int x, y;
        List<String> path;
        State(int x, int y, List<String> path) {
            this.x = x; this.y = y;
            this.path = new ArrayList<>(path);
            this.path.add("(" + x + ", " + y + ")");
        }
    }

    public static void solveBFS(int jug1, int jug2, int target) {
        if (target > Math.max(jug1, jug2) || target % gcd(jug1, jug2) != 0) {
            System.out.println("No solution exists."); return;
        }
        Queue<State> q = new LinkedList<>();
        boolean[][] visited = new boolean[jug1 + 1][jug2 + 1];
        q.add(new State(0, 0, new ArrayList<>()));
        visited[0][0] = true;

        while (!q.isEmpty()) {
            State cur = q.poll();
            if (cur.x == target || cur.y == target) {
                System.out.println("Goal Reached in " + (cur.path.size() - 1) + " steps:");
                for (String step : cur.path) System.out.println(" -> " + step);
                return;
            }
            int[][] next = {
                {jug1, cur.y}, {cur.x, jug2}, {0, cur.y}, {cur.x, 0},
                {cur.x - Math.min(cur.x, jug2 - cur.y), cur.y + Math.min(cur.x, jug2 - cur.y)},
                {cur.x + Math.min(cur.y, jug1 - cur.x), cur.y - Math.min(cur.y, jug1 - cur.x)}
            };
            for (int[] n : next) {
                if (!visited[n[0]][n[1]]) {
                    visited[n[0]][n[1]] = true;
                    q.add(new State(n[0], n[1], cur.path));
                }
            }
        }
    }
    private static int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }
    public static void main(String[] args) { solveBFS(4, 3, 2); }
}

# Experiment 3: Tic-Tac-Toe Minimax Algorithm (Python)
import math

def evaluate(board):
    lines = [[0,1,2],[3,4,5],[6,7,8],[0,3,6],[1,4,7],[2,5,8],[0,4,8],[2,4,6]]
    for a, b, c in lines:
        if board[a] == board[b] == board[c] and board[a] != ' ':
            return 10 if board[a] == 'X' else -10
    return 0

def minimax(board, depth, is_max):
    score = evaluate(board)
    if score != 0: return score
    if ' ' not in board: return 0

    if is_max:
        best = -math.inf
        for i in range(9):
            if board[i] == ' ':
                board[i] = 'X'
                best = max(best, minimax(board, depth + 1, False))
                board[i] = ' '
        return best
    else:
        best = math.inf
        for i in range(9):
            if board[i] == ' ':
                board[i] = 'O'
                best = min(best, minimax(board, depth + 1, True))
                board[i] = ' '
        return best

def find_best_move(board):
    best_val, best_move = -math.inf, -1
    for i in range(9):
        if board[i] == ' ':
            board[i] = 'X'
            val = minimax(board, 0, False)
            board[i] = ' '
            if val > best_val:
                best_val, best_move = val, i
    return best_move

print("=== Tic-Tac-Toe Minimax Move Selection ===")
print("Best Move Index for X:", find_best_move(board))

# Experiment 4: Informed A* Search Algorithm (Python)
class Graph:
    def __init__(self, adj, h_map):
        self.adj = adj
        self.h = h_map

    def a_star(self, start, stop):
        open_set = {start}
        closed_set = set()
        g = {start: 0}
        parents = {start: start}

        while open_set:
            n = min(open_set, key=lambda v: g[v] + self.h.get(v, float('inf')))
            if n == stop:
                path = []
                while parents[n] != n:
                    path.append(n)
                    n = parents[n]
                path.append(start)
                path.reverse()
                return path

            open_set.remove(n)
            closed_set.add(n)

            for m, weight in self.adj.get(n, []):
                if m in closed_set: continue
                if m not in open_set: open_set.add(m)
                tentative_g = g[n] + weight
                if tentative_g < g.get(m, float('inf')):
                    g[m] = tentative_g
                    parents[m] = n
        return None

# Graph Definition
adj = {'A': [('B', 1), ('C', 3)], 'B': [('D', 5)], 'C': [('D', 1)], 'D': [('G', 2)]}
h = {'A': 4, 'B': 2, 'C': 2, 'D': 1, 'G': 0}
g = Graph(adj, h)

print("=== A* Search Algorithm ===")
print("Optimal Path A -> G:", g.a_star('A', 'G'))

    class PerceptronPure:
        def __init__(self, lr=0.1, epochs=20):
            self.lr = lr
            self.epochs = epochs
            self.weights = [0.0, 0.0]
            self.bias = 0.0

        def fit(self, X, y):
            for _ in range(self.epochs):
                for xi, target in zip(X, y):
                    net = sum(w * x for w, x in zip(self.weights, xi)) + self.bias
                    pred = 1 if net >= 0 else 0
                    err = target - pred
                    self.weights = [w + self.lr * err * x for w, x in zip(self.weights, xi)]
                    self.bias += self.lr * err

        def predict(self, X):
            return [1 if sum(w * x for w, x in zip(self.weights, xi)) + self.bias >= 0 else 0 for xi in X]

# Experiment 7: McCulloch-Pitts Neuron Model (Python)
def mcculloch_pitts(inputs, weights, threshold):
    net = sum(x * w for x, w in zip(inputs, weights))
    return 1 if net >= threshold else 0

print("=== McCulloch-Pitts Logic Gates ===")
# AND Gate (weights=[1, 1], threshold=2)
for x1, x2 in [(0,0), (0,1), (1,0), (1,1)]:
    print(f"AND({x1}, {x2}) =", mcculloch_pitts([x1, x2], [1, 1], 2))

# OR Gate (weights=[1, 1], threshold=1)
for x1, x2 in [(0,0), (0,1), (1,0), (1,1)]:
    print(f"OR({x1}, {x2})  =", mcculloch_pitts([x1, x2], [1, 1], 1))

# NOT Gate (weight=[-1], threshold=0)
for x in [0, 1]:
    print(f"NOT({x})     =", mcculloch_pitts([x], [-1], 0))

# Experiment 9: Text Preprocessing & Cleaning UDF for Generative AI (Python)
import re
import string

def clean_text(text):
    text = str(text).lower()
    text = re.sub(r'http\S+|www\S+', '', text)
    text = re.sub(r'<.*?>', '', text)
    text = text.translate(str.maketrans('', '', string.punctuation))
    text = re.sub(r'\d+', '', text)
    text = re.sub(r'\s+', ' ', text).strip()
    return text
