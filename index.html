## 🤖 MODULE 1: AI AGENTS & PEAS FRAMEWORK (EXPERIMENT 1)

### Q1: What is an AI Agent? What is an Agent Function vs Agent Program?
- **Agent:** Anything that perceives its environment through **sensors** and acts upon that environment through **actuators**.
- **Agent Function:** Mathematical mapping from percept sequence to action: $f: P^* \rightarrow A$. (Abstract specification).
- **Agent Program:** Concrete software implementation of the agent function executing on a physical architecture.

### Q2: What is the PEAS framework? Specify PEAS for an Automated / Self-Driving Car.
- **PEAS:** Performance measure, Environment, Actuators, Sensors.
- **For Automated Car:**
  - **P (Performance):** Passenger safety, speed, legality, comfort, fuel efficiency.
  - **E (Environment):** Roads, vehicles, pedestrians, weather conditions, traffic signals.
  - **A (Actuators):** Steering wheel, accelerator, brakes, horn, turn signals.
  - **S (Sensors):** Video cameras, LiDAR, radar, GPS, speedometer, accelerometer.

### Q3: What are the different dimensions of Agent Environments?
1. **Fully Observable vs Partially Observable:** Full access to complete world state at any time vs incomplete/noisy sensor data.
2. **Deterministic vs Stochastic:** Next state is completely determined by current state and agent action vs random/probabilistic outcomes.
3. **Episodic vs Sequential:** Current decision does not affect future decisions vs current actions alter all future choices.
4. **Static vs Dynamic:** Environment does not change while agent is deliberating vs changes concurrently.
5. **Discrete vs Continuous:** Finite, clearly defined states and time steps vs infinitely continuous states/time.
6. **Single-Agent vs Multi-Agent:** Only one agent operating vs multiple interacting/competing agents.

## 🚰 MODULE 2: STATE SPACE SEARCH & WATER JUG PROBLEM (EXPERIMENT 2)

### Q4: Formulate the Water Jug problem as a State Space Search.
- **State Representation:** An ordered pair $(x, y)$ where $x \in [0, J_1]$ is water in Jug 1, and $y \in [0, J_2]$ is water in Jug 2.
- **Initial State:** $(0, 0)$ (both jugs empty).
- **Goal State:** $(d, \cdot)$ or $(\cdot, d)$ where $d$ is the target amount (e.g. 2 gallons).
- **Operators / Production Rules:**
  1. Fill Jug 1: $(x, y) \rightarrow (J_1, y)$
  2. Fill Jug 2: $(x, y) \rightarrow (x, J_2)$
  3. Empty Jug 1: $(x, y) \rightarrow (0, y)$
  4. Empty Jug 2: $(x, y) \rightarrow (x, 0)$
  5. Pour Jug 1 into Jug 2 until full: $(x, y) \rightarrow (x - (J_2 - y), J_2)$
  6. Pour Jug 2 into Jug 1 until full: $(x, y) \rightarrow (J_1, y - (J_1 - x))$
  7. Pour all Jug 1 into Jug 2: $(x, y) \rightarrow (0, x + y)$
  8. Pour all Jug 2 into Jug 1: $(x, y) \rightarrow (x + y, 0)$

### Q5: What is the mathematical condition for the Water Jug Problem to be solvable?
- **Theorem:** The problem is solvable if and only if the desired quantity $d$ is a multiple of the greatest common divisor of the capacities:
  $$d \le \max(J_1, J_2) \quad \text{and} \quad d \pmod{\gcd(J_1, J_2)} == 0$$
- *Example:* For $J_1 = 4, J_2 = 3$, $\gcd(4, 3) = 1$. Since $2 \pmod 1 == 0$, 2 gallons is solvable!

### Q6: Why is Breadth-First Search (BFS) preferred over Depth-First Search (DFS) for Water Jug?
- BFS visits nodes level-by-level using a FIFO queue.
- It **guarantees finding the solution with the minimum number of pours/steps**.
- DFS may get trapped in an infinite cycle or follow a long sub-optimal path.

## 🎮 MODULE 3: GAME PLAYING & MINIMAX ALGORITHM (EXPERIMENT 3)

### Q7: What is the Minimax Algorithm? What game characteristics does it require?
- An adversarial game-tree search algorithm for **two-player, zero-sum, deterministic, perfect-information** turn-based games (like Tic-Tac-Toe, Chess).
- **MAX player:** Attempts to maximize the utility score (e.g., $+10$ for win).
- **MIN player:** Attempts to minimize MAX's score (e.g., $-10$ for loss).
- Backtracks leaf evaluations up the tree by choosing $\max$ at MAX levels and $\min$ at MIN levels.

### Q8: What is the Time and Space Complexity of Minimax?
- **Time Complexity:** $O(b^m)$ where $b$ is the branching factor and $m$ is maximum tree depth.
- **Space Complexity:** $O(bm)$ (using Depth-First Search).

### Q9: What is Alpha-Beta Pruning? Under what mathematical condition is a branch pruned?
- An optimization technique that eliminates subtrees without altering the final minimax decision.
- **$\alpha$ (Alpha):** The best (maximum) value MAX is guaranteed so far (initially $-\infty$).
- **$\beta$ (Beta):** The best (minimum) value MIN is guaranteed so far (initially $+\infty$).
- **Pruning Condition:** Prune when $\beta \le \alpha$. Any further exploration cannot change the ancestor's minimax choice.
- **Optimal Time Complexity:** With ideal move ordering, time complexity reduces from $O(b^m)$ to $O(b^{m/2})$.

## 🧭 MODULE 4: INFORMED HEURISTIC SEARCH & A* SEARCH (EXPERIMENT 5)

### Q10: What is the difference between Uninformed and Informed Search?
- **Uninformed (Blind) Search:** Has no information about how close a state is to the goal (e.g., BFS, DFS). Explores systematically.
- **Informed (Heuristic) Search:** Uses domain-specific heuristic knowledge $h(n)$ to estimate remaining distance to the goal, drastically reducing state exploration.

### Q11: Explain the A* Search evaluation function: $f(n) = g(n) + h(n)$.
- **$g(n)$:** The exact cost accumulated from the start node to current node $n$.
- **$h(n)$:** The estimated (heuristic) cost from node $n$ to the goal.
- **$f(n)$:** Total estimated cost of the cheapest solution path through node $n$.
- A* expands the node with the lowest $f(n)$ value from the Priority Queue (Open List).

### Q12: What is an Admissible Heuristic? Why is it mandatory in A*?
- **Definition:** A heuristic is admissible if it **never overestimates** the true cost to reach the goal:
  $$h(n) \le h^*(n) \quad \forall n$$
  where $h^*(n)$ is the true optimal cost.
- **Significance:** Admissibility guarantees that A* tree search is **complete and optimal** (always returns the shortest path).

### Q13: What is a Consistent (Monotonic) Heuristic?
- **Definition:** A heuristic is consistent if for every node $n$ and every successor $n'$ generated by action $a$:
  $$h(n) \le c(n, a, n') + h(n')$$
  (satisfies the triangle inequality).
- Consistency implies admissibility. With consistency, the first time A* visits a state, it is guaranteed to be on the optimal path.

### Q14: How does A* behave when $h(n) = 0$ or $g(n) = 0$?
- If $h(n) = 0$: $f(n) = g(n) \implies$ Becomes **Dijkstra's Algorithm / Uniform Cost Search (UCS)**.
- If $g(n) = 0$: $f(n) = h(n) \implies$ Becomes **Greedy Best-First Search** (fast, but sub-optimal).

## 📜 MODULE 5: LOGIC PROGRAMMING & PROLOG (EXPERIMENT 6)

### Q15: What is PROLOG? What logic paradigm does it use?
- PROLOG (Programming in Logic) is a declarative logic programming language.
- Based on **First-Order Predicate Calculus** restricted to **Horn Clauses** (clauses with at most one positive literal).
- Instead of writing step-by-step algorithms, programmer declares **Facts** and **Rules**, and asks **Queries**.

### Q16: How does the PROLOG execution engine work?
- Uses **Resolution Refutation** with **Unification** and **Backtracking** (Depth-First Search).
- **Unification:** The algorithmic process of finding a set of variable bindings that makes two terms identical.

### Q17: What is the Cut operator (`!`) in PROLOG? Distinguish Green Cut vs Red Cut.
- **Cut (`!`):** A built-in predicate that commits the system to all choices made since the parent goal was invoked, preventing backtracking.
- **Green Cut:** Only improves performance without changing the set of answers/solutions returned.
- **Red Cut:** Changes the declarative meaning and the solutions produced by the program.

## 🧠 MODULE 6: NEURAL NETWORKS & PERCEPTRON (EXPERIMENT 10)

### Q18: What is the McCulloch-Pitts Neuron Model?
- The earliest computational model of a biological neuron (1943).
- Has binary inputs $x_i \in \{0, 1\}$, fixed excitatory weights $+1$, and inhibitory inputs.
- Fires ($1$) if sum of excitatory inputs $\ge \theta$ (threshold) and no inhibitory input is active.

### Q19: Explain the Single-Layer Perceptron (SLP) and its Learning Rule.
- Introduced by Frank Rosenblatt (1958). Has learnable weights $w_i$ and a bias $b$.
- Net input: $z = \sum w_i x_i + b$. Output: $y = 1$ if $z \ge 0$, else $0$.
- **Perceptron Learning Rule:**
  $$w_i \leftarrow w_i + \eta (y_{\text{target}} - y_{\text{actual}}) x_i$$
  where $\eta$ is the learning rate ($0 < \eta \le 1$).

### Q20: What is Linear Separability? Why does a Single-Layer Perceptron fail on XOR?
- **Linear Separability:** Data classes can be separated by a single straight line (in 2D) or hyperplane (in $n$D).
- **AND and OR** are linearly separable.
- **XOR (Exclusive-OR)** is NOT linearly separable: points $(0,1)$ and $(1,0)$ require class 1, while $(0,0)$ and $(1,1)$ require class 0. No single line can separate them! Hence SLP fails on XOR (Minsky & Papert, 1969).

### Q21: How does a Multi-Layer Perceptron (MLP) solve the XOR problem?
- MLP introduces one or more **Hidden Layers** with non-linear activation functions (Sigmoid, ReLU).
- The hidden layer maps the non-linearly separable inputs into a transformed feature space where they become linearly separable.
- Trained using the **Backpropagation Algorithm** (Gradient Descent with chain rule).

## 🌫️ MODULE 7: FUZZY LOGIC & FUZZY SETS (EXPERIMENT 7)

### Q22: What is the fundamental difference between Crisp Sets and Fuzzy Sets?
- **Crisp Set:** Binary boundary. An element either belongs or does not belong: $\mu_A(x) \in \{0, 1\}$.
- **Fuzzy Set:** Gradual boundary. An element has a degree of membership between 0 and 1: $\mu_A(x) \in [0, 1]$.

### Q23: Define standard Fuzzy Set Operations (Union, Intersection, Complement).
- **Fuzzy Union ($A \cup B$):** Maximum membership:
  $$\mu_{A \cup B}(x) = \max(\mu_A(x), \mu_B(x))$$
- **Fuzzy Intersection ($A \cap B$):** Minimum membership:
  $$\mu_{A \cap B}(x) = \min(\mu_A(x), \mu_B(x))$$
- **Fuzzy Complement ($\bar{A}$):** Difference from 1:
  $$\mu_{\bar{A}}(x) = 1 - \mu_A(x)$$

### Q24: What is Fuzzy Max-Min Composition?
- Given fuzzy relations $R(X, Y)$ and $S(Y, Z)$, their composition $T = R \circ S$ is:
  $$\mu_T(x, z) = \max_{y \in Y} \left( \min(\mu_R(x, y), \mu_S(y, z)) \right)$$

### Q25: What is Defuzzification? Explain the Centroid Method.
- **Defuzzification:** The mathematical process of converting a fuzzy set / membership distribution into a single crisp scalar value.
- **Centroid Method (Center of Gravity / COG):** Finds the balance point of the fuzzy area:
  $$z^* = \frac{\sum z \cdot \mu(z)}{\sum \mu(z)} \quad \left( \text{or } \frac{\int z \mu(z) dz}{\int \mu(z) dz} \right)$$
  Most widely used defuzzification method due to intuitive physical meaning.

Water Jug Solver in Java (WaterJugSolver.java)

import java.util.*;

public class WaterJugSolver {
    static class State {
        int x, y;
        List<String> path;

        State(int x, int y, List<String> path) {
            this.x = x;
            this.y = y;
            this.path = new ArrayList<>(path);
            this.path.add("(" + x + ", " + y + ")");
        }
    }

    public static void solveBFS(int jug1, int jug2, int target) {
        System.out.println("\nSolving Water Jug Problem using BFS (Shortest Path):");
        System.out.println("Jug 1 Capacity: " + jug1 + "L | Jug 2 Capacity: " + jug2 + "L | Target: " + target + "L");

        if (target > Math.max(jug1, jug2) || target % gcd(jug1, jug2) != 0) {
            System.out.println("Target cannot be measured according to Bezout's identity.");
            return;
        }

        Queue<State> queue = new LinkedList<>();
        boolean[][] visited = new boolean[jug1 + 1][jug2 + 1];

        queue.add(new State(0, 0, new ArrayList<>()));
        visited[0][0] = true;

        while (!queue.isEmpty()) {
            State current = queue.poll();

            if (current.x == target || current.y == target) {
                System.out.println("\nGoal State Reached!");
                System.out.println("Steps to solution (" + (current.path.size() - 1) + " operations):");
                for (int i = 0; i < current.path.size(); i++) {
                    System.out.println("Step " + i + ": " + current.path.get(i));
                }
                return;
            }

            List<int[]> nextStates = new ArrayList<>();
            nextStates.add(new int[]{jug1, current.y}); // Fill Jug 1
            nextStates.add(new int[]{current.x, jug2}); // Fill Jug 2
            nextStates.add(new int[]{0, current.y});    // Empty Jug 1
            nextStates.add(new int[]{current.x, 0});    // Empty Jug 2

            int pour1to2 = Math.min(current.x, jug2 - current.y);
            nextStates.add(new int[]{current.x - pour1to2, current.y + pour1to2});

            int pour2to1 = Math.min(current.y, jug1 - current.x);
            nextStates.add(new int[]{current.x + pour2to1, current.y - pour2to1});

            for (int[] next : nextStates) {
                int nx = next[0], ny = next[1];
                if (!visited[nx][ny]) {
                    visited[nx][ny] = true;
                    queue.add(new State(nx, ny, current.path));
                }
            }
        }
        System.out.println("No solution exists.");
    }

    private static int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("========================================");
        System.out.println("   Water Jug Problem Solver (AISC Exp 2)");
        System.out.println("========================================");
        System.out.println("1. Use default: Jug1 = 4L, Jug2 = 3L, Target = 2L");
        System.out.println("2. Enter custom values");
        System.out.print("Enter choice (1/2): ");

        int choice = 1;
        if (sc.hasNextInt()) {
            choice = sc.nextInt();
        }

        int j1 = 4, j2 = 3, target = 2;
        if (choice == 2) {
            System.out.print("Enter capacity of Jug 1: ");
            j1 = sc.nextInt();
            System.out.print("Enter capacity of Jug 2: ");
            j2 = sc.nextInt();
            System.out.print("Enter target amount: ");
            target = sc.nextInt();
        }

        solveBFS(j1, j2, target);
        System.out.println("========================================");
    }
}

# Water Jug Problem Solver (Python Recursive DFS / State Search)
from collections import defaultdict

jug1, jug2, aim = 4, 3, 2
visited = defaultdict(lambda: False)

def waterJugSolver(amt1, amt2):
    if amt1 == aim and amt2 == 0:
        print(f"Reached goal state: ({amt1}, {amt2})")
        return True

    if not visited[(amt1, amt2)]:
        print(f"Current state: ({amt1}, {amt2})")
        visited[(amt1, amt2)] = True

        return (waterJugSolver(0, amt2) or                       # Empty Jug 1
                waterJugSolver(amt1, 0) or                       # Empty Jug 2
                waterJugSolver(jug1, amt2) or                    # Fill Jug 1
                waterJugSolver(amt1, jug2) or                    # Fill Jug 2
                waterJugSolver(amt1 + min(amt2, (jug1 - amt1)),   # Pour Jug 2 -> Jug 1
                               amt2 - min(amt2, (jug1 - amt1))) or
                waterJugSolver(amt1 - min(amt1, (jug2 - amt2)),   # Pour Jug 1 -> Jug 2
                               amt2 + min(amt1, (jug2 - amt2))))
    else:
        return False

🎮 Experiment 3: Tic-Tac-Toe Game Playing

Adversarial Minimax Algorithm with Optimal Move Selection

Tic-Tac-Toe Minimax in Java (TicTacToeMinimax.java)

import java.util.Scanner;

public class TicTacToeMinimax {
    static final char HUMAN = 'X';
    static final char AI = 'O';
    static final char EMPTY = ' ';

    public static void printBoard(char[][] board) {
        System.out.println("");
        for (int i = 0; i < 3; i++) {
            System.out.println(" " + board[i][0] + " | " + board[i][1] + " | " + board[i][2]);
            if (i < 2) System.out.println("---|---|---");
        }
        System.out.println("");
    }

    public static boolean isMovesLeft(char[][] board) {
        for (int i = 0; i < 3; i++)
            for (int j = 0; j < 3; j++)
                if (board[i][j] == EMPTY) return true;
        return false;
    }

    public static int evaluate(char[][] b) {
        for (int row = 0; row < 3; row++) {
            if (b[row][0] == b[row][1] && b[row][1] == b[row][2]) {
                if (b[row][0] == AI) return +10;
                else if (b[row][0] == HUMAN) return -10;
            }
        }
        for (int col = 0; col < 3; col++) {
            if (b[0][col] == b[1][col] && b[1][col] == b[2][col]) {
                if (b[0][col] == AI) return +10;
                else if (b[0][col] == HUMAN) return -10;
            }
        }
        if (b[0][0] == b[1][1] && b[1][1] == b[2][2]) {
            if (b[0][0] == AI) return +10;
            else if (b[0][0] == HUMAN) return -10;
        }
        if (b[0][2] == b[1][1] && b[1][1] == b[2][0]) {
            if (b[0][2] == AI) return +10;
            else if (b[0][2] == HUMAN) return -10;
        }
        return 0;
    }

    public static int minimax(char[][] board, int depth, boolean isMax) {
        int score = evaluate(board);
        if (score == 10) return score - depth;
        if (score == -10) return score + depth;
        if (!isMovesLeft(board)) return 0;

        if (isMax) {
            int best = -1000;
            for (int i = 0; i < 3; i++) {
                for (int j = 0; j < 3; j++) {
                    if (board[i][j] == EMPTY) {
                        board[i][j] = AI;
                        best = Math.max(best, minimax(board, depth + 1, false));
                        board[i][j] = EMPTY;
                    }
                }
            }
            return best;
        } else {
            int best = 1000;
            for (int i = 0; i < 3; i++) {
                for (int j = 0; j < 3; j++) {
                    if (board[i][j] == EMPTY) {
                        board[i][j] = HUMAN;
                        best = Math.min(best, minimax(board, depth + 1, true));
                        board[i][j] = EMPTY;
                    }
                }
            }
            return best;
        }
    }

    public static int[] findBestMove(char[][] board) {
        int bestVal = -1000;
        int[] bestMove = {-1, -1};
        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                if (board[i][j] == EMPTY) {
                    board[i][j] = AI;
                    int moveVal = minimax(board, 0, false);
                    board[i][j] = EMPTY;
                    if (moveVal > bestVal) {
                        bestMove[0] = i;
                        bestMove[1] = j;
                        bestVal = moveVal;
                    }
                }
            }
        }
        return bestMove;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("========================================");
        System.out.println("  Tic-Tac-Toe Minimax Agent (AISC Exp 3)");
        System.out.println("========================================");
        System.out.println("You are 'X' and AI is 'O'. Position numbers 1 to 9:");
        System.out.println(" 1 | 2 | 3 ");
        System.out.println("---|---|---");
        System.out.println(" 4 | 5 | 6 ");
        System.out.println("---|---|---");
        System.out.println(" 7 | 8 | 9 ");

        char[][] board = {
            {' ', ' ', ' '},
            {' ', ' ', ' '},
            {' ', ' ', ' '}
        };

        System.out.println("\nAI calculating optimal response if Human plays center (pos 5):");
        board[1][1] = HUMAN;
        printBoard(board);

        int[] aiMove = findBestMove(board);
        System.out.println("Minimax AI selects row " + aiMove[0] + ", col " + aiMove[1] + " (Optimal Corner response)");
        board[aiMove[0]][aiMove[1]] = AI;
        printBoard(board);

        System.out.println("Strategy: Minimax Decision Tree (Adversarial Search)");
        System.out.println("Result: AI is theoretically unbeatable (always wins or draws).");
        System.out.println("========================================");
    }
}

🧭 Experiment 5: Informed Heuristic Search (A* Algorithm)

Shortest Path Graph Traversal evaluating f(n) = g(n) + h(n)

A* Search Algorithm in Java (AStarSearch.java)

import java.util.*;

public class AStarSearch {
    static class Node implements Comparable<Node> {
        int id;
        int g;
        int h;
        int f;
        Node parent;

        Node(int id, int g, int h, Node parent) {
            this.id = id;
            this.g = g;
            this.h = h;
            this.f = g + h;
            this.parent = parent;
        }

        public int compareTo(Node o) {
            return Integer.compare(this.f, o.f);
        }
    }

    static class Edge {
        int target, weight;
        Edge(int target, int weight) {
            this.target = target;
            this.weight = weight;
        }
    }

    public static void runAStar(Map<Integer, List<Edge>> graph, int[] heuristics, int start, int goal) {
        PriorityQueue<Node> openList = new PriorityQueue<>();
        Map<Integer, Integer> bestG = new HashMap<>();

        openList.add(new Node(start, 0, heuristics[start], null));
        bestG.put(start, 0);

        System.out.println("\n--- A* Search Node Expansion ---");
        System.out.println("Node\tg(n)\th(n)\tf(n)");

        while (!openList.isEmpty()) {
            Node current = openList.poll();
            System.out.printf("N%d\t%d\t%d\t%d\n", current.id, current.g, current.h, current.f);

            if (current.id == goal) {
                System.out.println("\nGoal Node " + goal + " reached with optimal cost: " + current.g);
                printPath(current);
                return;
            }

            for (Edge edge : graph.getOrDefault(current.id, Collections.emptyList())) {
                int newG = current.g + edge.weight;
                int neighbor = edge.target;

                if (!bestG.containsKey(neighbor) || newG < bestG.get(neighbor)) {
                    bestG.put(neighbor, newG);
                    openList.add(new Node(neighbor, newG, heuristics[neighbor], current));
                }
            }
        }
        System.out.println("Goal node is unreachable.");
    }

    private static void printPath(Node goalNode) {
        List<Integer> path = new ArrayList<>();
        Node curr = goalNode;
        while (curr != null) {
            path.add(curr.id);
            curr = curr.parent;
        }
        Collections.reverse(path);
        System.out.print("Optimal Path: ");
        for (int i = 0; i < path.size(); i++) {
            System.out.print("N" + path.get(i) + (i < path.size() - 1 ? " -> " : ""));
        }
        System.out.println();
    }

    public static void main(String[] args) {
        System.out.println("========================================");
        System.out.println("      A* Search Algorithm (AISC Exp 4)");
        System.out.println("========================================");

        int[] heuristics = {10, 8, 5, 7, 3, 0};
        Map<Integer, List<Edge>> graph = new HashMap<>();
        for (int i = 0; i < 6; i++) graph.put(i, new ArrayList<>());

        graph.get(0).add(new Edge(1, 2));
        graph.get(0).add(new Edge(2, 4));
        graph.get(1).add(new Edge(3, 7));
        graph.get(1).add(new Edge(4, 3));
        graph.get(2).add(new Edge(4, 1));
        graph.get(3).add(new Edge(5, 5));
        graph.get(4).add(new Edge(5, 4));

        System.out.println("Graph configured with Start = N0, Goal = N5");
        System.out.println("Heuristics h(n): N0=10, N1=8, N2=5, N3=7, N4=3, N5=0");

        runAStar(graph, heuristics, 0, 5);
        System.out.println("Evaluation Function: f(n) = g(n) + h(n)");
        System.out.println("Optimality: A* is optimal if heuristic h(n) is admissible (never overestimates).");
        System.out.println("========================================");
    }
}

        double[] B = {0.6, 0.4, 0.7, 0.1};

        printSet("Fuzzy Set A", A);
        printSet("Fuzzy Set B", B);

        int n = A.length;
        double[] union = new double[n];
        double[] intersection = new double[n];
        double[] compA = new double[n];
        double[] compB = new double[n];
        double[] diffAB = new double[n];

        for (int i = 0; i < n; i++) {
            union[i] = Math.max(A[i], B[i]);
            intersection[i] = Math.min(A[i], B[i]);
            compA[i] = 1.0 - A[i];
            compB[i] = 1.0 - B[i];
            diffAB[i] = Math.min(A[i], 1.0 - B[i]);
        }

        System.out.println("\n--- Standard Fuzzy Operations ---");
        printSet("Union (A ∪ B)        [max]", union);
        printSet("Intersection (A ∩ B) [min]", intersection);
        printSet("Complement (A')      [1 - A]", compA);
        printSet("Difference (A - B)   [A ∩ B']", diffAB);

        System.out.println("\n--- Cartesian Product (A × B) ---");
        double[][] cartesian = new double[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                cartesian[i][j] = Math.min(A[i], B[j]);
                System.out.printf("%.2f\t", cartesian[i][j]);
            }

        }

        System.out.println("\n--- Max-Min Composition Demo ---");

    }

import java.util.Scanner;

public class Perceptron {
    public static void trainPerceptron(int[][] inputs, int[] targets, String gateName) {
        double[] weights = {0.0, 0.0};
        double bias = 0.0;
        double lr = 0.1;
        int epochs = 10;

        System.out.println("\n--- Training Perceptron for " + gateName + " Gate ---");
        System.out.println("Learning Rate: " + lr);

        for (int epoch = 1; epoch <= epochs; epoch++) {
            int totalError = 0;
            for (int i = 0; i < inputs.length; i++) {
                double net = inputs[i][0] * weights[0] + inputs[i][1] * weights[1] + bias;
                int output = (net >= 0) ? 1 : 0;
                int error = targets[i] - output;
                totalError += Math.abs(error);

                weights[0] += lr * error * inputs[i][0];
                weights[1] += lr * error * inputs[i][1];
                bias += lr * error;
            }

            if (totalError == 0) {
                System.out.println("Converged at Epoch " + epoch + "!");
                break;
            }
        }

        System.out.printf("Final Weights: w1 = %.2f, w2 = %.2f, bias = %.2f\n", weights[0], weights[1], bias);
        System.out.println("Verification Table:");
        System.out.println("x1\tx2\tTarget\tPredicted\tStatus");
        for (int i = 0; i < inputs.length; i++) {
            double net = inputs[i][0] * weights[0] + inputs[i][1] * weights[1] + bias;
            int pred = (net >= 0) ? 1 : 0;
            System.out.println(inputs[i][0] + "\t" + inputs[i][1] + "\t" + targets[i] + "\t" + pred + "\t\t" + (pred == targets[i] ? "MATCH" : "FAIL"));
        }
    }

    public static void main(String[] args) {
        System.out.println("========================================");
        System.out.println("   Single-Layer Perceptron (AISC Exp 6)");
        System.out.println("========================================");

        int[][] inputs = {
            {0, 0},
            {0, 1},
            {1, 0},
            {1, 1}
        };

        int[] andTargets = {0, 0, 0, 1};
        int[] orTargets = {0, 1, 1, 1};

        trainPerceptron(inputs, andTargets, "AND");
        trainPerceptron(inputs, orTargets, "OR");

        System.out.println("\nNote: SLP can solve linearly separable problems (AND, OR).");
        System.out.println("XOR is non-linearly separable and requires Multi-Layer Perceptron (MLP).");
        System.out.println("========================================");
    }
}
